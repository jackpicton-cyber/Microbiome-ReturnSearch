Microbiome Exchange in the Built Environment: Literature Search Repository
Edit: 07/21/2026
This repository contains the full search results, screening records, and supporting data underlying the structured literature review "Dynamics of Microbiome Exchange in the Built Environment: A Structured Review" (Picton, 2026).

Overview

This review examined the current peer-reviewed literature on bidirectional microbial exchange between humans and the built environment. Databases were searched on 23 October 2025, using controlled vocabulary and keyword terms across PubMed and Embase. This repository preserves the complete search output, including studies excluded during screening, to support transparency and reproducibility of the review process.

Search Strategy Summary
Step	Count
Total records identified (PubMed + Embase)	195
Duplicates removed	31
Records screened (title/abstract)	164
Records excluded at title/abstract screening	134
Studies meeting full inclusion criteria	30

Inclusion criteria: Full-text articles were included if they (I) involved microbiome assessment; (II) addressed microbial load, diversity, or transfer between humans and the built environment, whether through primary data collection or synthesis of existing evidence; (III) employed or discussed recognizable microbial detection methods (e.g., qPCR, 16S rRNA sequencing, ITS sequencing, culturing, metagenomics) where applicable to the study design; (IV) addressed indoor or built environments broadly, including but not limited to homes, hospitals, offices, schools, and public transportation.

Screening was conducted in two passes: an initial title/abstract review, followed by full-text evaluation. Ambiguous or borderline studies were reassessed to confirm inclusion decisions.

How to Use This Repository
To see which studies were ultimately included in the review, start with the Included Citations (30) tab.
To trace a specific study's screening history (why it was included or excluded), check the Title_Abstract Inclusion tab.
To review the complete, unfiltered search output for either database, see the corresponding search results .docx file or the PubMed Entries / Embase Entries tabs.
Notes
All DOIs in this repository were verified and corrected for formatting errors (e.g., stray characters, trailing punctuation) as of July 2026.
This repository reflects the search and screening record as of the review's most recent revision. Screening decisions may be updated as the review is refined; see file modification history for the most current version.
